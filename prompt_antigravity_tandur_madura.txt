4. MODEL KNN & FILE .joblib
--------------------------------------------------------------------------------
train_model.py (bisa dijalankan mandiri: python train_model.py) dan juga diimpor app.py:
  - Baca xlsx, validasi kolom/tipe, buang baris kosong/duplikat.
  - Pipeline scikit-learn:
      ColumnTransformer(
        [("cat", OneHotEncoder(handle_unknown="ignore", sparse_output=False), [kabupaten, musim, jenis_tanah]),
         ("num", StandardScaler(), [suhu, kelembapan, curah_hujan, ph_tanah, ketinggian])])
      -> KNeighborsClassifier(n_neighbors=K, metric=..., weights=...)
  - Split stratified 80/20, random_state=42.
  - Cari K terbaik dengan 5-fold StratifiedKFold CV pada K = 1..25, metrik {euclidean, manhattan},
    weights {uniform, distance}. Pilih kombinasi terbaik (akurasi CV tertinggi; seri -> K lebih kecil).
  - Latih ulang pada data latih, hitung akurasi/precision/recall/F1 (data uji), simpan ke:
      models/knn_crop_madura.joblib  berisi dict:
        {"pipeline": <Pipeline>, "k": int, "metric": str, "weights": str,
         "classes": list, "feature_names": {...}, "metrics": {...},
         "n_train": int, "n_test": int, "trained_at": ISO-datetime,
         "sklearn_version": str, "data_file": str}
  - Cetak ringkasan hasil di terminal.
app.py:
  - Muat joblib dengan st.cache_resource. Jika file belum ada, ATAU gagal dimuat
    (mis. beda versi scikit-learn di server), otomatis latih ulang & simpan, lalu lanjut
    tanpa crash (tampilkan notifikasi kecil "Model dilatih ulang otomatis").
  - Tombol "Latih Ulang & Simpan Model (.joblib)" dan "Unduh model .joblib" (st.download_button)
    di halaman Evaluasi & Optimasi K. Setelah latih ulang: kosongkan cache dan rerun.
  - Tampilkan info model aktif (K, metrik, weights, akurasi, tanggal latih, versi sklearn).
